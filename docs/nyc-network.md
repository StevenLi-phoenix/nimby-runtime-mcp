# 纽约地铁全网复现

目标仍为完整纽约地铁网络，包含共线基础设施、不同停站服务、分支、换乘和运营验收。已建 Franklin Avenue Shuttle 只是其中一条线路。

## 数据与审计

- `prepare_nyc_network.py` 与 `data/nyc_network_inventory.json` 保存从 OSM 线路索引发现并经 API 读回的 28 个 route master。
- `prepare_nyc_route_index.py` 与 `data/nyc_route_index.json` 保存其 109 个方向／时段变体、完整停站成员及轨道候选成员。
- 共有 2,346 个唯一轨道候选 way，其中 1,010 个被多个 master 使用。此阶段只证明来源成员相同；不能证明完整实体轨网、几何连续性或已建造。
- Q 线关系 `9712345` 的来源 `route=bus`、`network:wikidata=Q6967576` 与线路身份不一致，列入异常。不得自动纳入施工；需结合另一方向、轨道数据和运营方资料核对，不在 OSM 上修改来源。
- 主网络旧关系 `2621040` 已返回 410；全网发现不依赖该失效对象。

## L 线

`prepare_nyc_l.py` 从显式输入快照生成 `data/nyc_l_plan.json`。来源关系 `366763`、`9716996` 分别验证 24 站顺序及连续轨道链，保留 242／252 个源轨道节点，单向约 16.48 公里。站名逐项映射至 [MTA L 线站序](https://www.mta.info/maps/subway-line-maps/l-line)。

规划保留双向独立源几何与桥隧标签。Wilson Avenue 南行来源层级为 1，北行为 0，不能简单复制同层双线。3rd Avenue 南行 stop 位于 -1／-2 的 way 分界，记录两个相邻层级供人工核对，不能把分界归属当作真实双层车站的证据。8th Avenue 来源 -4 超出当前原生编辑范围，候选采用 -3；后续换乘线仍需逐处核对交叉层级。站台采用项目默认 140 米及 120 米替代车辆。

现场查询覆盖 24 个站点各 1,500 世界米半径，查询时未发现既有轨道；这不是全市空白证明，也不能替代继续施工前的局部读回。

L 线 24 站、23 段区间及两端站后折返已通过原生选区建造，共 447 个 Medium 节点、288 个附属建筑。建造后读回无蓝图残留，附属建筑与轨道层级一致；施工扣款 120,599,847。施工保护列表包含两个北京节点及既有 Franklin Shuttle 节点，原生命令已验证保护对象状态。

运营线路 `nyc-l`，ID `1125899908874241`，双向 48 个有向停站，默认停站 20 秒，票价为游戏起步 3、每公里 0。12 列 Kayou 231 六节替代列车已采购、编号为 `nyc-l-0001` 至 `nyc-l-0012`，购车扣款 158,400,000。参考列车 ID `1407374900789250`，客运服务值为 2。初次有界运行推进 640 个游戏秒，12 列车均读到载客，最高观测 111 人。此结果只证明初始载客运行，完整往返、站台方向和实际折返位置仍需图形验收，不能宣称已全部验收。最终恢复暂停，游戏时间 `1793149023`。

Wilson Avenue 采用同一 station 下地面／高架各一股轨道，移除本次自动生成的八个渡线节点，前后区间按双向独立来源几何连接。3rd Avenue 采用地下一层，出站后过渡到来源地下二层。New Lots Avenue 南侧未标层级的路堤位于两座一级桥之间，保持一级至最后桥端，再向显式地面区段下降，避免错误的短距离下沉再抬升。

两端各设置约 400 实际米尾轨及渡线。8th Avenue 尾轨保持地下三层；Canarsie 地面终点外采用局部地下尾轨，这是满足游戏站后折返要求的适配，并非声称现实存在该设施。未建设车辆段或库线。Broadway Junction 北侧无层级标签的短桥梁引道采用一级过渡，修复地面控制点与道路的原生冲突；原始来源保持不变。

独立检查点为 `work/nyc-l-built.json`；恢复时先查现场，不能重复建站、购车或添加停站。记录包含首次创建的状态副本恢复，以及一次错误尾轨端点选择后的原生读回恢复；均先确认执行结果再继续，没有重复施工。后续继续其他线路、共线基础设施与换乘归属，完整纽约地铁目标尚未完成。
